Features

Everything you need to review your clips

Browse, watch and manage all your Sentry Mode events from a single, focused interface.

📹

4-camera synchronized view

Watch front, back, left-repeater and right-repeater cameras simultaneously, perfectly synced in real time.

🔌

Automatic USB detection

Plug in your Tesla USB drive and TesLEr instantly discovers all available SentryClips volumes — no setup needed.

📍

Location & timestamp

Each event card shows the city, estimated coordinates and the exact date & time the alert was triggered.

⏩

Auto-advance playback

Automatically moves to the next clip when playback ends so you can review a full session hands-free.

🗑️

Batch delete

Select multiple clips at once and delete them in a single action to keep your drive tidy.

💻

Cross-platform

Available on macOS (Apple Silicon & Intel), Windows x64, and Linux via the Snap Store.

Modern open-source stack
